Bug fix release.

## Fixed

- **Memory use back to ~10 MB.** Voltray 0.1.0 used about 60 MB in the background: the taskbar text and the quick panel were drawn with a GPU-backed Direct2D target, which creates a graphics device for a few tiny images. They are now drawn in software, with the same look.

## Download

- **Voltray-0.1.1-setup.exe**: installer (updates 0.1.0 in place; your settings are kept).
- **Voltray-0.1.1-portable.zip**: no installation; extract and run `Voltray.exe`.

The files are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" the first time. Click **More info → Run anyway**.
