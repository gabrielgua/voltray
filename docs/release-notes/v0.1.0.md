First release of Voltray: battery levels of your wireless mouse, keyboard, headphones and controllers in the Windows tray or right on the taskbar.

## Download

- **Voltray-0.1.0-setup.exe**: installer. Installs for your user only (no admin rights), adds a Start menu entry and can start Voltray with Windows.
- **Voltray-0.1.0-portable.zip**: no installation. Extract anywhere and run `Voltray.exe` (keep the `settings` folder next to it).

The files are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" the first time. Click **More info → Run anyway**.

Requires Windows 10 version 2004 or later, 64-bit. Windows 11 recommended (acrylic panel, rounded corners).

## What it does

- **Tray icons or taskbar text.** One icon per device category or per device, in four styles; or the devices written on the taskbar next to the tray (symbol and percentage, with a level bar, or two compact rows).
- **Quick panel.** Left click (or hover, in taskbar mode) opens a panel with every connected device, each tile filled up to its battery level.
- **Compact window** with charging animations, per-device settings (show in tray, notifications, category, icon) and settings for start with Windows, refresh interval and alerts.
- **Low-battery notifications** with your own rules and messages; respects Do Not Disturb. Optional "charging complete" notice.
- **Battery history** with estimated time remaining.
